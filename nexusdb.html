01 / THE CHALLENGE

What problem does it address?

Understand how database systems actually store bytes, interpret SQL, maintain indexes, and recover from failure rather than relying on existing storage engines.

02 / THE APPROACH

How I approached it.

Co-designing a 12-week, two-developer implementation. My ownership covers disk pages, serialization, record storage, B+ tree indexing, and transaction durability. The other developer owns SQL parsing and developer-facing interfaces.

03 / KEY COMPONENTS

Inside the project.

  • Custom on-disk page format — planned
  • B+ tree indexing — planned
  • Single-writer transactions and WAL — planned
  • SQL / CLI integration — planned
04 / THE NEXT ITERATION

Where it goes next.

Agree on storage contracts, initialize Rust workspace, write page manager tests, and verify persistence across restart.
