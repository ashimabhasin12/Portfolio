Stored-Grain Pest Classification.

An image-classification study comparing convolutional neural networks and vision transformers on stored-grain insects.

01 / THE CHALLENGE

What problem does it address?

Explore model suitability for classifying pest images using a small three-class dataset.

02 / THE APPROACH

How I approached it.

Conducted comparative experiments with VGG and ResNet families alongside DeiT transformer variants. Organized training, evaluation, and academic reporting with a team collaborator.

03 / KEY COMPONENTS

Inside the project.

  • Roughly 3,000+ images across 3 classes
  • Images standardized to 224 × 224
  • CNN and transformer comparisons
  • Final report and project poster
04 / THE NEXT ITERATION

Where it goes next.

Improve data quality, class balance and experimental rigor before using models in practical pest monitoring.

Project note

Experiments were exploratory; reported results should not be interpreted as deployment-grade accuracy.
