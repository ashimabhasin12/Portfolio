01 / THE CHALLENGE

What problem does it address?

Turning resistance-gene annotations into useful, validated machine-learning features requires repeatable preprocessing and careful handling of sparse labels.

02 / THE APPROACH

How I approached it.

Contributed to a BioML Lab capstone exploring MEGARes-enriched ARGProfiler outputs and downstream machine-learning features. Investigated issues such as insufficient class counts for stratified cross-validation.

03 / KEY COMPONENTS

Inside the project.

  • Pipeline and feature design
  • MEGARes / ARGProfiler integration exploration
  • Modeling experiments
  • Evaluation constraints documented
04 / THE NEXT ITERATION

Where it goes next.

Consolidate reproducible evaluation and expand appropriately labeled datasets before drawing strong performance claims.
