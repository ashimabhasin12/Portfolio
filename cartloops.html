01 / THE CHALLENGE

What problem does it address?

Traditional shopping interfaces can be frustrating when users need hands-free interaction or want help finding products.

02 / THE APPROACH

How I approached it.

Developed a Django-based shopping experience with product browsing, a speech-to-text interaction, and a chatbot interface. Explored how voice and conversational UX can make digital shopping more approachable.

03 / KEY COMPONENTS

Inside the project.

  • Django-backed web application
  • Speech-to-text interaction demonstrated
  • Chatbot integration demonstrated
  • Responsive shopping interface
04 / THE NEXT ITERATION

Where it goes next.

Improve automated accessibility audits, integrate more reliable product search, and document deployment.
