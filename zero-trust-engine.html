01 / THE CHALLENGE

What problem does it address?

IoT and wireless sensor environments need mechanisms for recognizing unusual signal behavior and supporting trustworthy device access.

02 / THE APPROACH

How I approached it.

Working with a four-person team to design a wireless security prototype. My assigned focus is dataset organization and feature extraction, including signal variance, skewness, kurtosis and environmental context. The team switched to an external Zigbee RF fingerprint dataset while waiting for hardware.

03 / KEY COMPONENTS

Inside the project.

  • I/Q dataset and metadata workflow
  • Statistical feature-extraction plan
  • Python backend and local data pipeline architecture
  • Team documentation and GitHub process
04 / THE NEXT ITERATION

Where it goes next.

Validate features on available data, integrate modeling and dashboard behavior, and document reliable evaluation.
